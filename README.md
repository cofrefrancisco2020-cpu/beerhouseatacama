# Beer House Atacama — versión 1

Sitio estático responsive listo para un repositorio de GitHub y un despliegue en Vercel. No requiere compilación ni dependencias de JavaScript.

## Abrir y desplegar

1. Abre `index.html` para una vista local, o sirve esta carpeta con cualquier servidor estático.
2. Sube el contenido de esta carpeta como raíz del repositorio de GitHub.
3. En Vercel, importa el repositorio, selecciona **Other** como framework y deja vacío el comando de build. El directorio de salida es la raíz del proyecto.

## Contenido

- `index.html`: secciones, metadatos, enlaces y contenido.
- `styles.css`: diseño responsive, animaciones y adaptación a movimiento reducido.
- `script.js`: navegación móvil, filtros, carrusel y revelado al desplazarse.
- `assets/`: logo, fotos reales de los productos, registros del Instagram y mapa de Gallo 541.
- `brief-marca.md`: investigación, fuentes y procedencia de imágenes.

## Fuentes y mantenimiento

El sitio se basa en el [Instagram oficial](https://www.instagram.com/beerhouseatacama/) y en la [carta oficial](https://queresto.com/BHT). Las presentaciones citadas son anteriores; la agenda actual se consulta en Instagram. No hay platos creados con IA. Los precios son orientativos y deben cotejarse con la carta antes de publicar. El horario publicado en el perfil es miércoles a lunes desde las 16:00, martes cerrado.

La ubicación del mapa corresponde a las coordenadas enlazadas desde la carta oficial. La imagen del mapa está incluida en el sitio y funciona sin conexión; el enlace de indicaciones abre Google Maps y sí requiere internet. El mapa conserva el crédito de OpenStreetMap contributors y MapMap. Antes del lanzamiento público, confirma con la marca la autorización para reutilizar las fotos de la carta y el registro del concierto de @piwkeaukan / @memoriadefuego. Si se asigna dominio, actualiza la URL de `og:image` por una URL absoluta del sitio. Las fuentes web y los enlaces externos necesitan conexión a internet.
